# ServidorCRUD

## Objetivo
Implementar un servidor HTTP nativo utilizando Node.js para realizar operaciones CRUD de productos y clientes.

## Tecnologías utilizadas
- Node.js
- TypeScript
- HTTP nativo
- JSON
- Postman

## Instalación
pnpm install

## Ejecución
pnpm run dev

## Rutas Disponibles

### Productos
GET /productos
GET /productos/:id
POST /productos
PUT /productos/:id
DELETE /productos/:id

### Clientes
GET /clientes
GET /clientes/:id
POST /clientes
PUT /clientes/:id
DELETE /clientes/:id
